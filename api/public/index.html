ECE1779 Task Manager mini admin console

Login, create projects and tasks, assign members, update status, search, and inspect activity logs.

1. Login Authenticate and keep session cookies

Once logged in, all API calls reuse the same session.

2. Create Project Attach a project to an existing team

You must belong to the team to create a project under it.

3. Create Task Minimal payload for demo

If provided, users will be assigned and an activity log entry is created.

On success, the new task ID is filled into the controls below.
